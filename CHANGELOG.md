# Changelog

## 0.2.0 — V1.1
- Minimum break between sessions (`--min-break`).
- Weighted minimization of idle minutes and active days.
- Separate idle, active-day, and objective-score metrics.
- Ten new parameterized and behavioral test cases.

## 0.3.0 — V2
- Streamlit dashboard with interactive Plotly weekly calendar.
- JSON upload, editable constraints, strategy comparison and CSV export.
- Four tests for dashboard input/output helpers.

## 0.4.0 — V2.1
- Added editable availability table with add/remove rows and input validation.
- Added weekly calendar with all seven weekdays and full-day axis.
- Added dual-axis comparison chart and preserved comparison results across reruns.
- Added download of edited input JSON and editor validation tests.
- Updated Streamlit width parameters to supported API.

## Release preparation (unreleased)

- Keep application logic unchanged from V2.1.
